# daamper-tools

Conjunto de herramientas y scripts diseñados para mantener, migrar y actualizar el sistema [daamper](https://github.com/armindeck/daamper) hacia sus versiones más recientes.

## 📦 Contenido

Este repositorio contiene scripts para:

- Copiar publicaciones, usuarios y configuraciones antiguas.
- Convertir estructuras de versiones anteriores (v0.1.x / v0.2.x) a la nueva estructura JSON de v0.3.0.
- Realizar tareas de mantenimiento y depuración.
- Aplicar cambios masivos a los archivos sin perder datos previos.

## 📁 Archivos

- `migrador.php`: Script para convertir los archivos antiguos a la nueva estructura.
- `readme.md`: Este archivo.
- `license.txt`: Licencia del repositorio.

## ✅ Requisitos

- PHP 8.2+
- Permisos de lectura/escritura en los archivos a migrar
- Tener una copia de seguridad antes de ejecutar cualquier script
